# Vault Hunters: A Borderlands Field Guide

Welcome to **Pandora**, Vault Hunter. This repo is an unofficial, fan-made field guide to the **Borderlands** series, the looter-shooter franchise from Gearbox Software. It started in 2009 with a simple promise: shoot things, collect guns, find the Vault.

## The Basics

- **Pandora**: a dusty, dangerous planet with bandits, skags and a lot of loot.
- **The Vault**: a legendary alien vault said to hold unimaginable power and treasure.
- **Eridium**: the glowing purple mineral that Vaults and alien tech run on.
- **Claptrap**: a small, cheerful, extremely talkative robot who will follow you everywhere.

## Loot Rarity

Every gun drops in a rarity tier, usually shown by color:

| Color  | Rarity    |
|--------|-----------|
| White  | Common    |
| Green  | Uncommon  |
| Blue   | Rare      |
| Purple | Epic      |
| Orange | Legendary |

Legendary drops are the whole reason people keep playing.
